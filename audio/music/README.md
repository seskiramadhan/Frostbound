# Music

Public tracks (committed, played on the live site). Use these exact names:

| File | When it plays | Track | Licence |
|---|---|---|---|
| `explore.mp3` (or `.ogg`) | Valley, village, dungeons | "Medieval: Exploration" by RandomMind (OpenGameArt) | CC0 |
| `boss.mp3` (or `.ogg`) | Dragon fights, final boss | "Boss Battle Music" by SubspaceAudio (OpenGameArt) | CC0 |

Only add tracks you are allowed to publish (CC0 / CC-BY with credit listed here).

## Personal tracks: `local/`
Files in `audio/music/local/` are ignored by git and never uploaded. Put your own
`explore.mp3` / `boss.mp3` there to hear them when playing locally (start.bat);
they replace the public tracks with the same name.
